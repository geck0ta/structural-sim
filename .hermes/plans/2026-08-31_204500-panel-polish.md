## Task 4: Picker "Contoh kasus" → dropdown menempel tombol (bukan bottom sheet)

**Objective:** Sheet pilihan muncul tepat di bawah tombol pemicu di panel kanan; tak lagi menutupi ribbon chart di bawah layar.

**Files:**
- Modify: `src/ui/glass/picker.ts` — `open()`: hitung posisi dari tombol
- Modify: `src/style.css:728-748` — `.picker-sheet` transparan tanpa dim; card fixed via inline style

**Step 1:** `picker.ts` — ganti isi `open()` (posisi + close luar tetap):
```ts
  private open(): void {
    if (this.sheet) return;
    const sheet = document.createElement('div');
    sheet.className = 'picker-sheet';
    const card = document.createElement('div');
    card.className = 'picker-card glass';
    const t = document.createElement('div');
    t.className = 'picker-title';
    t.textContent = this.title;
    card.append(t);
    // ... (bari opsi yang sudah ada — JANGAN diubah, lanjutkan sampai append ke sheet)
    // Anchor: card fixed di bawah tombol pemicu, rata kiri tombol.
    const r = this.el.getBoundingClientRect();
    card.style.position = 'fixed';
    card.style.top = `${Math.min(r.bottom + 6, window.innerHeight - 80)}px`;
    card.style.left = `${Math.max(8, Math.min(r.left, window.innerWidth - 260))}px`;
    card.style.width = `${Math.max(r.width, 240)}px`;
    document.body.append(sheet);
    this.sheet = sheet;
  }
```
(Close handler + Esc yang sudah ada di file tetap — verifikasi dengan membaca sisa `open()` sebelum patch; jangan duplikat listener.)

**Step 2:** `style.css`:

  animation: picker-up 180ms cubic-bezier(0.32, 0.72, 0, 1);

## Risks & Tradeoffs

- **Task 4 (picker anchored):** card fixed bisa kepotong kalau tombol di dekat bawah viewport — sudah di-mitigasi `Math.min(r.bottom + 6, innerHeight - 80)`; opsi tetap butuh scroll internal (`max-height: 50vh`). Escape scroll-clipping panel: karena `position: fixed`, panel `overflow` tak memotong.
- **Task 5:** mengganti stroke halo ke `--surface-2` bergantung token ada di semua tema (light/dusk/dark) — verifikasi ketiganya; fallback `color-mix` disediakan.
- **Task 6:** menghapus `height: 172px` berisiko chart kolaps jika anak pakai `height: 100%` — solusi cadangan sudah ditulis (tinggi eksplisit di row chart). Ini pola bug accordion `style.display` lama: cek anak sebelum commit.
- **Semua task:** tidak menyentuh solver/FEM — 31 test harus tetap hijau tiap task; kalau merah, berarti ada sentuhan tak sengaja ke core — rollback `git checkout -- src/core src/structural`.
